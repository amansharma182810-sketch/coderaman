# MongoDB Full-Stack Projects

Three recruiter-friendly MongoDB projects are organized here:

## 1. Job Application Tracker
React + Node.js + Express + MongoDB. Track applications, stages, interviews, notes and follow-ups.

## 2. E-Commerce API
Node.js + Express + MongoDB. Products, categories, carts, orders, inventory and admin-ready APIs.

## 3. Expense Analytics
React + Node.js + Express + MongoDB. Transactions, categories, budgets and aggregation-based analytics.

Each project is an original portfolio implementation, designed to be extended into a complete production application.
