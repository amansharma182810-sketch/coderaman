# Clinic Management SaaS

A production-style clinic operations application built with React, Node.js/Express, PostgreSQL and Socket.IO.

## Planned modules
- Receptionist dashboard
- Patient registration
- Doctor schedules
- Appointments and walk-ins
- Queue tokens and estimated wait time
- Patient records and visit history
- Billing
- Role-based access
- Real-time queue updates
- Audit-friendly activity history

## Stack
React • Node.js • Express • PostgreSQL • Socket.IO

This is an original portfolio implementation inspired by common clinic-management SaaS patterns.
