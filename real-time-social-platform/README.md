# Real-Time Social Platform

A recruiter-focused social application built with React, Node.js, Express, MongoDB and Socket.IO.

## Planned features
- JWT authentication
- User profiles
- Posts, likes and comments
- Follow system
- Real-time notifications
- Real-time chat
- Search and feed
- Image uploads
- Admin moderation

## Stack
React • Node.js • Express • MongoDB • Socket.IO

## Run
Create frontend and backend `.env` files from the examples, install dependencies, then start both applications.
